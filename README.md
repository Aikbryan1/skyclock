# Skyclock 🌍⏰

A beautiful world clock app that displays current time across different cities with dynamic backgrounds based on the time of day.

## Features

- 🌍 View current time in multiple cities worldwide
- 🌅 Dynamic backgrounds (Morning/Afternoon/Evening/Night)
- 🎨 Clean, modern UI with gradient overlays
- 📱 Responsive design for all devices

## Tech Stack

- Flutter
- Dart
- Timezone package for accurate time calculations

## Installation

### Android

Download the APK from [Releases](https://github.com/Aikbryan1/skyclock/releases)
